# 🍽️ SmartDinePro - Hotel & Restaurant Management System

SmartDinePro is a full-stack Hotel & Restaurant Management System built using **Django**, **Django REST Framework**, **React.js**, and **MySQL/SQLite**. It streamlines restaurant and hotel operations by providing modules for menu management, table reservations, QR ordering, inventory, billing, employee management, hotel room booking, and business reporting.

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/VishalKokatnur/SmartDinePro_Hotel_and_Restaurant.git
```

```
cd SmartDinePro_Hotel_and_Restaurant
```

---

## Backend Setup

Create Virtual Environment

```bash
python -m venv venv
```

Activate Virtual Environment

### Windows

```bash
venv\Scripts\activate
```

### Linux / Mac

```bash
source venv/bin/activate
```

Install Dependencies

```bash
pip install -r requirements.txt
```

Run Migrations

```bash
python manage.py makemigrations
python manage.py migrate
```

Seed Sample Menu

```bash
python manage.py seed_menu_items
```

Start Backend

```bash
python manage.py runserver
```

---

## Frontend Setup

```bash
cd frontend
```

Install Packages

```bash
npm install
```

Start React App

```bash
npm start
```
